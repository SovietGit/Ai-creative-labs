## 1. Задача и критерий

Набор из 12 объектов публикуется университетом как открытый учебный, без коммерческого использования; Нужно определить, какие материалы с условием NoDerivatives конфликтуют со сценарием, и предложить, чем их заменить или как использовать без изменения.

Политика использования: коммерческое использование - нет; публикация или передача набора — да; создание производных работ — да; допустимо передавать производные на тех же условиях — да.

Критерий успеха. Решение по каждой находке; паспорт набора данных и карточка модели без пустых разделов; реестр рисков с проверкой PASS.

## 8. Вывод и ограничения

Вывод: набор не может быть опубликован в текущем виде. Три объекта (item01, item04, item12) под лицензией CC-BY-ND-4.0 блокируют сценарий, требующий права на создание производных. Ещё один объект (item08) не имеет указанного правообладателя, что нарушает условие атрибуции MIT. После исключения ND-объектов и проведения проверки на персональные данные набор может быть признан условно пригодным для некоммерческого учебного использования - при условии явного указания ограничений в README и паспорте набора. Ряд вопросов (толкование NoDerivatives, применимость MIT к данным, достаточность заявления об отсутствии PII) не может быть закрыт инженерно и требует юридического заключения.

Ограничения: Понятие «без изменений» проверять по сценарию: кадрирование или сжатие может считаться изменением — записать вопрос юристу.
