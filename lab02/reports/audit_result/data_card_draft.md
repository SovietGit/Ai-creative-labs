# Паспорт набора данных (заготовка, разделы по Gebru и др., 2018)

Сценарий использования: открытый учебный набор университета (некоммерческий).

## 1. Motivation (мотивация)
Набор собран для подготовки и распространения открытых учебных материалов университета; пользователи — преподаватели, студенты и методисты. (некоммерческое использование)

## 2. Composition (состав)

* Число объектов: 12; по типам: audio — 4, text — 4, image — 4.
* Распределение лицензий: CC0-1.0 — 4, CC-BY-ND-4.0 — 3, MIT — 3, Apache-2.0 — 1, CC-BY-4.0 — 1.
* Объектов с персональными данными: 0.
* Объектов, для которых лицензия требует указания авторства: 8 (список авторов нужно публиковать вместе с набором).
* Результаты аудита: ошибок — 3, предупреждений — 1.

## 3. Collection Process (процесс сбора)
* Даты получения: 2026-01-06 … 2026-08-28.
* Источники: example.org.
Материалы поступали из внешних архивов (вымышленные домены); согласия на персональные данные не собирались, персональных данных в наборе нет.

## 4. Preprocessing/cleaning/labeling (обработка и разметка)
По итогам аудита исключены объекты item01, item04, item12 (конфликт лицензий CC-BY-ND-4.0: условие NoDerivatives запрещает производные, а сценарий их предполагает); для item08 запрошен правообладатель - до его подтверждения объект не используется. Разметка не выполнялась.

## 5. Uses (использование)
* Предполагаемое: открытый учебный набор университета (некоммерческий); коммерческое использование — нет; производные — да.
Не подходит для публикации набора под единой лицензией без переоценки условий оставшихся объектов; не подходит для коммерческого использования; не подходит для производных от объектов под NoDerivatives.

## 6. Distribution (распространение)
* Публикация набора — предполагается; условия зависят от лицензий объектов (раздел 2).

## 7. Maintenance (сопровождение)
Ответственный — куратор данных учебного проекта (назначается распоряжением по факультету/кафедре); запросы правообладателей об удалении и запросы субъектов персональных данных принимаются по адресу проекта, регистрируются в журнале обращений и выполняются с обновлением манифеста (manifest.csv), пересчётом контрольных сумм SHA256 и присвоением новой версии набора. Ответ на обращение - в течение 30 календарных дней; при отзыве согласия или обоснованном требовании правообладателя объект исключается из текущей и последующих версий, а в паспорте набора фиксируется дата и причина исключения.
